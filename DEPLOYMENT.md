# Deployment (superseded)

The old Vercel deployment notes are superseded. CloudForge now runs fully on AWS
(S3 + CloudFront frontend, SAM backend with API Gateway, Lambda, S3, DynamoDB,
SQS, EventBridge, CloudWatch and SNS).

Follow **[docs/AWS_DEPLOY_GUIDE.md](docs/AWS_DEPLOY_GUIDE.md)** for the current,
step-by-step deployment in AWS CloudShell (us-east-1).
